# downstream_bin_a

The package of the `binext` distribution of the
[REP 159](https://github.com/openrobotics/reps/pull/32) test harness.
`binext` extends ROS 2 Lyrical with `extension_method: binary_import`: `rcl`
and everything below it are the official `ros-lyrical-*` debs, installed
under `/opt/ros/lyrical`, and only this package is built.

Index and distribution files: https://github.com/rep159-testing/rep159-rosdistro
